# Beamer 图表与科学可视化

本文件补充 Beamer 的绘图、插图和验证细节。工具探测与数据可靠性沿用[科学绘图工具与环境选择](scientific-visualization.md)；内容职责沿用[首次阅读与证据](audience-and-evidence.md)；可见边界、连接与签核分别执行[布局完整性](layout-integrity.md)、[连接完整性](connector-integrity.md)、[签核流程](signoff-workflow.md)。其中 PPTX 的对象寻址、原生图表接口和数值尺寸按 Beamer 的源组件、PDF 页面及实际显示比例适配。

## 先确定图解决的阅读任务

同时执行[图表含义与视觉归属](scientific-visualization.md#图表含义与视觉归属)：核对实际绘制量、图名和轴名，区分图例标记与数据点，把结构图放入对应方法的视觉组；代码和伪代码按其完整上下文核对必要输入与终止逻辑。

每幅图明确主张、数据或机制来源、读图顺序及结论范围。解释变量、单位、基线、颜色、误差条、对数尺度和面板关系；图内标签与正文之间能互相定位。多面板可以分别承担绝对值、相对值、机制、限制或误差来源等职责。信息密度由这些信息增量决定，保持有用细节，结合正文、公式、图表分配空间。

[起步工程](../assets/beamer-starter/README.md)用三页串起问题和递推、两种收敛尺度、停止条件与计算量。两面板分别看距离与目标值；右侧对数轴的含义在图下解释。曲线由确定公式生成，停止次数可用短循环复算。这类计算示例应明确模型条件，避免把函数上的结论扩展成所有优化问题的结论。

## 工具按已有能力选择

先检查当前环境中实际可执行的工具、库、字体、导出后端和必要许可证，再选择路线；完整探测流程见[工具选择](scientific-visualization.md#先探测后选择)。可用的工具可以组合使用。

| 工具或素材 | 合适用途 | Beamer 中的源与导出 |
|---|---|---|
| TikZ、PGFplots | 原生机制图、数学曲线、精确坐标、与正文统一的公式标签 | 保留 `.tex` 与输入数据；编入 PDF 后仍保留原生矢量文字和路径 |
| Python / Matplotlib 等 | 统计图、多面板、分布、误差条、热力图 | 保留代码、参数及数据，优先导出 PDF；检查字体嵌入及透明度 |
| MATLAB、GNU Octave | 工程计算、信号与控制图、已有 `.m` 工作流 | 使用已安装且可执行的批处理链，保留 `.m` 和数据；核对矢量导出与渲染器 |
| R / ggplot2 等 | 统计分析、分面、专用科学图形 | 保留 `.R` 和数据，使用可用的 PDF/SVG 后端；转换后复核字号与字形 |
| Graphviz、Julia、Gnuplot、现有 SVG 工具 | 关系结构、数值图、定制矢量图 | 按任务选已安装工具，保留编辑源及可复现导出命令 |
| 论文原图、网络图片、照片 | 原始观测、实物、现场、已有研究证据 | 核对来源、使用权限和图义，保留来源与原始文件；按最终显示尺寸选择清晰度 |

复杂数值计算可交给 Python、MATLAB 或 R，结果再交给 PGFplots 排版。简单解析曲线可直接用 PGFplots 表达式计算。选择取决于精度、速度、数据规模和可维护性；TeX 宏内数值精度需要实际核验。

Beamer 的矢量优先通常指可编辑源加矢量 PDF 成品。外部 PDF 中的每个对象是否能被其他软件单独修改，要按用户要求另行确认；“保留绘图源”与“交付对象级可编辑演示文稿”分别描述。SVG 常需已有工具转换为 PDF；使用 `svg` 宏包时同时核查转换命令、缓存及执行权限。照片等连续色调内容采用合适分辨率的位图。

默认保留原图、原始像素与分辨率；不为减小文件体积进行有损转码、降采样或统一转 JPEG，矢量素材保持矢量。单张图超过 20 MB（20,000,000 bytes）时，可询问是否需要压缩；未收到答复则继续使用原图。获得压缩授权后只生成副本，保留原件，并重新检查文字、细节、颜色和最终显示效果。调整嵌入显示大小、裁切 viewport，以及生成整页预览图均属于展示或验证操作，源图保持不变。

## 画图区、图片外框与有效区域分别测量

1. **数据画图区**是坐标轴围成的矩形，多面板比较时常需对齐。
2. **完整图框**包含轴标题、刻度、指数、图例、面板字母及注释，决定与邻栏的实际间距。
3. **图片 viewport / bounding box**决定 TeX 如何定位和占位；其中可能含大面积白边。
4. **有效内容区域**是可见字形、路径及图像主体所在区域，用于判断视觉大小、对齐与内容密度。

PGFplots 的 `scale only axis` 把 `width` 和 `height` 用于轴矩形。外侧标签另占空间；默认整体尺寸估计也需要最终看图。`groupplots` 的面板间隔应同时容纳相邻面板的纵轴标签、刻度和标题。共享图例需让读者明确哪些曲线使用同一映射。

外部图可使用双尺寸限幅：

```tex
\includegraphics[width=\linewidth,height=4.5cm,keepaspectratio]{figure.pdf}
```

若需要裁掉白边，先打开原图核对完整内容，再按测量值设置：

```tex
\includegraphics[width=\linewidth,
  trim=6bp 4bp 6bp 4bp,clip]{figure.pdf}
```

`trim` 的顺序是左、下、右、上；示例数值只表达语法。`viewport=llx lly urx ury` 采用源图坐标，需结合该文件的边界和单位确定。检查带 `clip` 的最终效果，以及负值扩展区域时的占位结果。坐标轴末端、箭头尖、上标、图例、比例尺和来源标注都在裁切保护范围内。修改 bounding box、使用 `overlay` 或 `\useasboundingbox` 会影响占位，不会自动证明墨迹完整；实际路径和可见标签仍需查看。

## 按最终插入尺寸定字体和线宽

优先调整原生轴尺寸、字体、标记和线宽，再考虑外层缩放。`\resizebox`、`\scalebox` 或图片插入缩放会同时改变文字、线宽与间距；嵌套缩放的倍率相乘。

等比缩放时，`最终字号 = 源字号 × 总缩放倍率`。例如 10 TeX pt 标签缩到 80%，有效大小为 8 TeX pt，约 7.97 PDF bp；0.8 pt 曲线也变为 0.64 pt。尺寸检查需与原生页面大小、最终观看尺度一起判断。PowerPoint 的 point、PDF bp 与 TeX pt 的换算按 Beamer 工作流处理，避免直接套用另一画布的字号数值。

图中文字仍参加可读性检查，包括位图中的标签、节点中的公式、指数因子、单位、脚注和边缘注释。先按共享语义字号试排，再按真实问题调整列宽、图内间距、布局或局部字号；记录实际改善。多面板保留比较尺度与必要解释，密集图可以增加说明或重排组件，使每块空间承担明确任务。

## 复杂连接与最终复核

TikZ 或外部工具生成的流程、回路、网络和跨面板箭头按[连接完整性](connector-integrity.md)逐根检查起点、终点、锚点、分支、路径和标签。检查箭头是否触达目标、是否穿过文字、不同线型是否可辨；有 overlay 时检查每个实际输出状态。TeX 节点中心和容器边界可作定位依据，最后以可见节点和路径判断。

先检查独立图，再在最终 PDF 中放大检查局部，随后回到正常整页检查层级、对齐、留白及页脚保护。覆盖全部实际 PDF 页及 overlay 状态。warning 用于定位缺字、字体回退、标签或盒尺寸问题；其数量不充当视觉质量分数。局部位移、负间距、空盒、精细小数、显式断行等按具体作用与最终效果使用。

版式规则未通过或无法可靠测量时，保存原结果并执行[局部＋整页独立视觉兜底](signoff-workflow.md#版式规则未通过时的视觉兜底)。确认误报或完成修复后继续验证；可见裁切、错义、缺字和重叠应修复。验证记录留在工作目录，图表成品保留主题内容及必要来源。
