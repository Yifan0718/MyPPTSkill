# 科学绘图工具与环境选择

用于学术研究、数学公式、实验数据、统计分析、仿真、网络结构或其他高级科学图表。根据图表需要选择工具，不要求每次把所有工具都用一遍。必须同时遵守本地内容、字号、篇幅、可编辑性和可视化验收要求。

## 先探测，后选择

- 优先使用现有任务运行时及项目依赖，检查可执行文件、版本和必要库是否可用。安装目录存在不等于完整可用；选定工具后用轻量、无副作用的版本/依赖检查确认。
- Windows 同时考虑本机与 **已安装的 WSL**。本机可用 `Get-Command` 检查 python、Rscript、matlab、octave、julia、latexmk、pdflatex、xelatex、lualatex、tectonic、dot、gnuplot、inkscape、wolframscript、node 等；命令不在 PATH 时可检查任务已知运行时或明确的常见安装位置，避免无目的全盘扫描。
- 先检查 `wsl.exe` 与已有发行版（例如 `wsl --list --quiet`）。只有已存在且可正常启动的发行版才可使用；在明确选定的发行版中用 `command -v` 等方式检查工具及依赖。不存在 WSL、发行版或对应工具时直接跳过，不启用 Windows 功能、不新装发行版、不修改默认发行版或系统 PATH。
- WSL 文件访问通过明确的 Windows/WSL 路径转换完成，数据和输出留在任务工作目录。避免字符串拼接造成转义错误；调用前确认文件可读，输出后确认 Windows 侧可用。不要把项目复制到无关位置或改动原始数据。
- 只读检测可并行；实际绘图、编译及导出按依赖顺序执行。GUI 工具优先使用已支持的批处理或无界面接口，避免弹出无关窗口。
- 工具、绘图库、字体、导出后端或许可证不可用时，记录并选择可用替代。**不自动 pip/npm/conda/apt 安装依赖，不安装 MATLAB/TeX/R，不购买或激活许可证。** 若用户另有明确安装授权，再依该授权处理。
- 探测结果只描述当前环境，不把“此次没安装”永久写成禁用规则；后续任务按需要重新检查。不要凭工具名称出现在本文件就宣称它已经安装。

## 按任务选用工具

| 已可用的工具 | 适合的任务 | 使用前额外检查 |
|---|---|---|
| Python：Matplotlib、Seaborn、Plotly、Altair、Bokeh | 多面板科研图、误差线、分布、热力图、三维图、统计可视化 | 库、字体及实际导出后端；Plotly 等的图片导出依赖也须可用 |
| R：ggplot2、lattice、ComplexHeatmap 等 | 统计图、分面、复杂热力图、研究领域专用绘图 | Rscript 与所需包，使用 requireNamespace 等检查；不自动安装 |
| MATLAB | 信号、控制、数值仿真、工程图与已有 .m 工作流 | 可执行程序、许可证及所需 toolbox；使用批处理接口 |
| GNU Octave | 可兼容的 .m 数值分析与工程图 | 语法、包和绘图后端；不能假设完全兼容 MATLAB |
| LaTeX：TikZ、PGFPlots、公式排版 | 数学公式、严谨技术示意图、精确坐标与标注 | 编译器、宏包、中文字体及 SVG/PNG/PDF 转换链；禁止隐式自动下载缺失宏包 |
| Julia：Makie、Plots 等 | 数值计算、科学模拟和高质量二维/三维图 | Julia、已有包及后端 |
| Graphviz / Mermaid | 有向关系、流程、依赖、状态机和结构图 | dot 或现有 Mermaid CLI/渲染器；复杂布局仍需人工检查 |
| Gnuplot | 数据曲线、函数曲面及可重复批量绘图 | 可执行程序和输出终端支持 |
| Node.js：Vega/Vega-Lite、D3、现有 SVG 工具 | 声明式统计图、定制图表及 SVG 导出 | 已有包和静态渲染依赖 |
| Wolfram / Mathematica | 符号计算、数学与物理可视化 | 已可用的内核、接口与许可证 |
| ParaView、Blender 等 | 三维科学数据、几何、体渲染和空间关系 | 实际数据格式、脚本接口及渲染资源；不为一般柱图启动重型工具 |
| Inkscape、现有 SVG/PDF 转换工具 | 矢量整理、格式转换、字体兼容与导出检查 | 工具及转换结果，不把它们当作数据计算来源 |

以上为候选能力，未安装的项目跳过。可使用其他已安装且适合任务的工具，判断依据是表达能力、可靠性、可重复性和最终可读性。

## 图表与数据的可靠性

- 依据真实数据、明确公式或标注的模拟数据绘制。保留输入、代码、参数、随机种子（如使用随机过程）、单位和关键变换，避免工具默认设置造成误导。
- 核对坐标尺度、颜色映射、分组、误差线/区间、统计含义、图例与样本数量。自行计算的数字应能复算，不能把漂亮图形当作结果证明。
- 图表复杂度服务于科学问题；允许多面板、技术结构和高级图形，不因常规字号限制直接放弃。辅助文字按已授权的 12/10/8 pt 局部例外执行，普通表格困难时最低 10 pt，正文不借图形绕过字号规则。

## 放入 PPT 与最终验收

- 适合 PowerPoint 原生图表的内容优先保持原生可编辑；复杂科学图可用清晰的 SVG、EMF（环境兼容时）或按最终展示尺寸导出的高分辨率 PNG。PDF 可作中间矢量产物，插入前使用实际可用的转换链。用户明确要求对象级可编辑时，需满足该要求，不能把静态图片称为可编辑图表。
- 保存绘图源代码和数据到工作目录，便于修改及复现；用户请求时再作为交付物提供。不得在幻灯片中写“使用 Python/MATLAB 等工具生成”。
- 字号按插入后的最终尺寸检查。按图片在 PPT 中的实际缩放比例换算字号，同时检查图中文字的最终显示大小、线宽、对比度、背景、裁切和字体替换。
- 先查看导出的图形，再查看最终 PPT 的真实渲染。复杂图形可以局部放大检查，随后回到整页检查清晰度、图文间距、横纵均衡及页码保护。修复后重新渲染复查；全稿逐页 signoff 后才发布。
