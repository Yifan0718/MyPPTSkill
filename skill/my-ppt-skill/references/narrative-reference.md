# 发布会原则：按目的选用的叙事参照

这是用户明确要求固化的参照流程，不是所有 Slides 必须采用的宣传模板。制作大纲前根据用途、受众、材料与用户要求决定采用哪些方法；可混合使用，不必向用户逐项确认。用途不明确且会显著改变组织方式时，按 Skill 已有大纲确认规则询问。选择过程仅留在工作记录，不写进 PPT。

## 先判断演示承担什么任务

| 用途 | 组织重点 | 选用方式 |
|---|---|---|
| 产品发布、成果展示、提案 | 最强且有证据的优势、用户价值、关键结果 | 优先用发布会式叙事，主动说清优势与意义 |
| 客观比较、采购决策、行业分析 | 决策问题、评价维度、不同目标的适配 | 平等说明各方案的实际差异，不预设需要吹捧某一方 |
| 学术报告、论文讲解 | 研究问题、缺口、贡献、证据链 | 借鉴开场与贡献表达；保留方法、反证及影响结论成立的条件 |
| 项目复盘、工作汇报、教学 | 用户要求的进度、因果、过程或学习目标 | 保留必要过程，按问题与发现组织；不强行改成产品发布会 |

“PPT 是发布会”用于提醒作者重视听众理解与核心判断，不改变用户真实任务。学术文章可借鉴这一写作思路，但本 Skill 不因此扩展为所有文章任务的默认工具。

## 表达档位与逐页职责

先按用户明确要求选档，其次根据用途、受众、目标与已确认大纲推断；只有选择会明显改变选材且无法可靠判断时才问“更偏优势展示、优势主导、学术论证还是客观比较？”。与封面、篇幅、章节标识问题合并询问，已知信息不重复问。

| 档位 | 选材与讲法 |
|---|---|
| 优势展示 | 围绕最强且有证据的优势选材，负面结果和旁支通常不进正文；适合宣传、路演、成果发布 |
| 优势主导 | 保留任务需要的重要比较，讲述聚焦改善、实际价值及有证据的设计取舍；不主动展开自我批评 |
| 学术论证 | 按问题、贡献、方法与证据链组织，明确创新及支撑结论的条件；消融按论证职责选择 |
| 客观比较 | 用一致维度评价各方，不预设赢家；证据支持谁更适合就明确说明，不机械分配相同篇幅或赞美 |

四档都用自然直接语言。负数、基线、分母和研究范围按实际事实保留；优势展示选取有力证据，不把最佳个例写成总体表现。用户要求保留负面指标而侧重正面解读时采用优势主导，原值完整，解读聚焦确有支持的收益。必要条件融入对象或标签，不加泛化防御尾句。当前档位记录于任务文件，用户改方向时更新并核对选材，不机械继承到不同用途的新稿。

大纲给每页确定**论证职责、关键证据、前置概念、正文/附录位置**。引入大量额外概念而不推进已确认主线的材料优先放附录；影响主结论成立的事实应在相应论证处交代。直觉案例、操作流程、训练目标即使围绕同一概念，只要解决不同理解问题，就保留递进，不按词语重复机械合并。标题与所展示证据一致。示例选取执行[首次阅读与案例规范](audience-and-evidence.md#先确定案例职责再选择案例)。

## 可选择采用的六步流程

1. **确定核心判断。** 先回答听众应记住什么、为什么重要，再围绕最强的相关证据组织材料。客观比较的核心判断可以是适用场景或决策条件，不必是某一方案获胜。
2. **用问题带出价值。** 开场可采用“问题 → 缺口 → 思路 → 最硬的结果”。不机械要求四个标题或四页；用户要过程复盘时，保留支持因果解释的过程，不罗列无关尝试。
3. **让每份证据承担职责。** 每个实验、案例和图表应验证主张、解释机制、区分方案或界定适用条件。无职责的重复材料删除或合并；必要反证与负结果也可以承担职责，不能因不占优而删去影响判断的信息。
4. **主动解释发现。** 用图表标题、重点标注或简短结论直接说清证据支持的优势、变化及实际意义，不要求听众自行从密集表格猜结论。标题不超出图表能够证明的范围。
5. **按用途审查语气与比较。** 删除情绪化自贬、泛化免责与制作自述，换成具体机制、实际结果、行动或有依据的判断。客观比较直接陈述各方案在哪些条件下更合适；学术材料把实质条件融入方法、结果与讨论，不在结论后机械补一段自我削弱。
6. **结尾强化记忆点。** 回到核心贡献、最强结果和实际意义，不突然引入此前未讨论的否定性评价。已在正文论证的真实权衡或决策条件可自然纳入结论；不以夸张口号代替证据。

## 比较与表达的执行边界

- **评价维度服务于目标。** 可突出与目标最相关的优势，不把所有指标都变成排名比赛。比较采用一致单位、样本、条件与统计口径；不要看到结果后更换分母、筛掉关键对照或隐藏不利结果制造领先。
- **权衡需要证据。** 不占优时，如果确有精度—速度、成本—覆盖等权衡，直接说明获得什么、付出什么、适合谁；没有证据就如实陈述差异，不能为失败编造目标或合理化原因。
- **不机械禁词。** “遗憾的是”“效果有限”“仍明显落后”等常是自我削弱提示；“仅”也可能是在表达样本数量或资源效率。结合语义改写，不简单删词，也不删除准确的数值、估计属性、计划状态与必要技术条件。
- **风险与局限可以是实质内容。** 当它们影响科研结论、采购选择或用户要求的分析时，用具体发生条件、影响与应对表达。禁止的是泛化防御话术，不是客观事实和有效分析。
- **参照方法不产生新审批。** 不要求每页固定三段式，不因未采用发布会结构判为不合格，不新增页数、不删必要内容、不改变已确认的大纲。事实准确、用户任务与现有版面/渲染/签核要求继续执行。

文稿审查时检查：核心判断是否明确、证据是否承担职责、优势或适配条件是否说清、是否有无依据的权衡解释、结论是否呼应正文。按具体任务选择检查重点，不把这份参照变成机械打勾模板。
