# Beamer 制作与验收

交付执行[PDF与原始源码规则](latex-delivery.md)，回复中必须有PDF直达打开链接。

用于明确要求 LaTeX／Beamer／`.tex` 演示稿，或编辑已有 Beamer 工程。常规 PowerPoint 请求继续走 PPTX 路线。默认交付 PDF 与可编译源码工程；额外 PPTX、handout、讲稿或图片按用户需求提供。源码工程包含必要的图源、数据和主题依赖说明。

作者按用户提供或主题内容中的真实署名设置，未提供则留空；引用作者不替代演示作者。PDF保留题名等正常属性。构建器在最终哈希、渲染与审计之前，用`pdf_generator_metadata.py`清理Info和XMP中的生成程序身份，核对其余属性、页面、链接和原编码图片保持，并保留内部原始编译副本。XeLaTeX可覆盖源稿的空Producer设置，必须检查最终PDF。

## 共用规则与入口

执行[需求、内容与篇幅](local-delivery-quality.md)、[Affirmative-First Writing](affirmative-first-writing.md)、[首次阅读](audience-and-evidence.md)、[语义层级与信息充实度](presentation-hierarchy.md)、[精调方法](precision-layout.md)。叙事按[用途选择](narrative-reference.md)。主题页、公式页、代码页和各个 overlay 都讲实质内容；清理制作要求和验收自述。

封面、篇幅和实质不清楚的结构仍按需求流程询问。新稿默认16:9，入口显式写 `aspectratio=169` 并检查PDF尺寸；旧4:3/16:10模板用于新稿时重新分配空间。已有稿的局部修正沿用任务范围。独立章节页、导航、notes和附录按已确认用途设置，不能自动增页。未另行约定时按最终PDF物理页计篇幅，overlay每个输出状态也计页；页脚统一x/y并与该口径对应。使用frame计数需先明确，仍检查全部PDF页。

封面按已确认构图保留合理大留白，不套用正文页的填充密度要求，也不为填空自动加卡片或装饰；执行[封面构图例外](presentation-hierarchy.md#封面标题入口与信息去重)。色块内居中、对齐与内容完整性仍全量检查。

## 主题与字体

- 用户已有主题：在副本中读取主题、公共宏、字体和构建配置；保留风格，修正空白、换行和小字问题。
- 未指定其他风格：直接采用已确认的[BIO0507默认风格](beamer-default-style.md)，从starter复制工作工程并在theme.tex后加载bio0507-style.tex。用户要求换风格或本次选其他主题时，再展示实际编译的候选页，按[主题说明](beamer-themes.md)选择、锁定版本并保留许可。21套PPTX模板仍属于PowerPoint路线。
- 默认工程通过build_beamer自动调用setup_fonts，按锁定文件配置缓存与用户字体并生成myppt-fonts.tex；用户级注册失败但精确缓存字体可用时，Beamer继续按文件加载。原有工程可显式使用--configure-fonts。详情见[字体资源](bundled-fonts.md)。
- 检查现有latexmk、XeLaTeX／LuaLaTeX／pdfLaTeX、所用宏包、中文/拉丁/数学/代码字体。Windows同时考虑已存在的WSL，沿用[工具选择](scientific-visualization.md)。缺工具时选择可用路径；受控字体包按已获授权自动配置，其余安装需已有明确授权。字体文件或配置变化后重看受影响页，不用替代字体悄悄改变既定风格。
- 这项环境检测在数据计算、画图和编译之前完成，记录实际解释器路径。某个Python缺包时先检查已知可用运行时及替代工具，不直接pip安装；字体安装授权仅覆盖字体。
- 先建立语义字体角色，再调整局部。中文、英文、数字、数学上下标、代码和图内标签实际看图。`\fontsize{a}{b}` 的a和b分别控制请求字号与基线距；省略`\selectfont`可能只影响数学而保留文本大小，需按作用使用，不能机械改写。

## 长度和字号的适配

PowerPoint参考画布为960×540 point；标准16×9 cm Beamer的PDF页高约255.12 bp。PowerPoint point／PDF bp为72/in，TeX pt为72.27/in。**所有字号、间距、边距、页码隔离及数值审计容差按画布和有效缩放换算**，禁止直接套相同原始pt。

可用 `等效PPT字号 = PDF中实际字号(bp) / PDF页高(bp) × 540` 比较层级；缩放过的图和文字取最终实际尺寸。现有12／10／8pt的适用范围和例外证据按该等效值执行；Beamer源码的8 TeX pt不会因此自动触发8pt例外。相对换算只是起排依据，仍在正常整页判断可读性。常用起点为常规字重主标题14.4–17 TeX pt、正文9.5–11 TeX pt、图标签8–9 TeX pt，依据字体、主题和内容调整；关键解释与正文同级；辅助备注可适度缩小或使用较灰颜色，执行共用层级与同页字号比例规则。数学固有上下标按其语义和实际阅读检查，不能把普通注释伪装成上标。

等效8pt例外仅供确有必要的复杂技术图局部，保留等效10pt真实试排、冲突截图、尝试过的布局、内容必要性和拆图评估，绑定最终局部及整页；正文、普通表格和代码正文不取得该资格。全稿基准调整与少数页例外分开记录。

## 内容、图表与布局

每页明确听众获得的新知识、对应证据和需要的解释。按实际内容选择图文双栏、多面板比较、机制图、流程、公式推导、代码与效果对照。图表执行[Beamer图表处理](beamer-charts.md)及现有科学绘图规则。主体过空时补有依据的机制、代表性例子、同口径比较或结果解读，或重组已有内容；禁止为字号、间距或对齐规则删关键内容、缩小图表、制造空卡片、机械拆页。

分开管理：页面分区 → 组件内部 → 段落/列表/公式 → 光学微调。`columns[t]`首行基线与`[T]`顶部对齐的效果不同；`\vspace{0pt}`、strut、phantom、局部正负间距、显式空盒均按具体用途使用。检查实际字形和图形，包含被overlay或零尺寸盒绘出的内容。精调到小数或采用等义改写后，重看局部、整页及相关状态。

标题和block不默认普遍加粗，执行[字重校准](precision-layout.md#字重按字体和输出格式校准)。页脚背景、导航条及其文字按[三层留白](precision-layout.md#页脚和色带也检查内部余量)检查；正文安全距离不能机械变成页脚基线以下的大深度。参考Boadilla正常紧凑的页脚，再按真实字形微调。

## 构建与实际渲染

在工作副本中使用 `scripts/build_beamer.py --help` 获取本机命令参数；它构建PDF、逐页渲染并记录状态、页数、几何、日志、依赖和哈希。用[证据接口与命令](beamer-evidence.md)生成未核验的review骨架，实际看图填写后运行`verify_beamer_review.py`。工具返回成功只表示对应阶段完成，仍须实际视觉签核。提供已有PDF时，也要核对它对应当前源稿和实际页序列。

构建环境与主题配置固定后再精调。改动源、公共宏、字体、图源或构建模式后建立新候选；输入变化、旧PDF、空文件或缺页先恢复有效输出。实际依赖含字体、图片及嵌套input，按工具能力结合构建清单记录；单靠主tex哈希不足以描述全稿。

构建器同时运行`audit_beamer_layout.py`，记录每页文字、图片、路径及越界、小字、空白和标题入口候选。复杂结构与图片有效内容不以包围盒自动判好。可选解析器不可用时保留全部渲染，按受影响页生成测量不可用项，走真实独立局部＋整页复核后继续；不得用跳过审计开关自授免检。所有候选均绑定原PDF与审计哈希，issues为零仍逐页看图。

主体有色大容器保留外缘及全部可见图形，另检查内部实际内容。`body_container_content_review` 覆盖纯文字明显偏置、文字即使居中仍留下大块空区，以及包含图片或路径时外包络无法证明的真实内容与空区；保留容器、子对象和上下间隙量测。该候选通过当前容器局部覆盖＋整页＋独立复核继续；容器覆盖整页时，按证据接口使用多张局部联合覆盖，保持整页回看独立记录。合理的图形布局或有意留白按实际观察确认；文字偏置或内容缺失须修复。

分阶段处理故障：字体/宏包预检、TeX排版、辅助文件重跑、PDF转换、PDF打开、图像渲染。让latexmk按引用和页码收敛；直引擎方式另核对引用收敛。大量高分辨率PNG转换较慢时看CPU、日志与文件增长；可将XeLaTeX的XDV生成与xdvipdfmx转换分开、调整无损压缩级别，核对结果后继续。超时仅回收本次启动的进程树，保留日志和恢复路径。

## warning 与视觉判断

warning按具体对象定位，**无需零warning交付**。字体替换、Overfull/Underfull、rerun、不可见字符等分别核实；可见内容完整且效果良好的警告可保留。缺正文字符、公式符号、图例或已确认的可见遮挡则修复。清零日志不能作为牺牲版面或内容的理由。

零warning同样逐页看图，尤其固定高度卡片、TikZ overlay、手动bounding box、缩放图、复杂公式和代码。不可读PDF、输入变化、漏页和构建执行失败进入修复或替代路径；有效PDF中的版式误报进入下述独立视觉复核，不把拦截当作停工结论。

## 最终检查与签核

继承[签核流程](signoff-workflow.md)的内容遍、版式遍、全量/增量范围和独立视觉兜底；PPTX的COM/XML/shape_id校验器仅用于PPTX，Beamer使用本节的源组件与PDF证据，不伪造shape_id调用旧脚本。

1. 从当前稳定PDF生成逐页整图，逐页检查内容遍与版式遍。总览图辅助比较跨页风格，不代替逐页检查。检查所有实际页，包括封面、章节、附录和overlay中间状态；需要handout时另检查该输出。
2. 内容遍检查首次可读性、术语、公式符号、证据、图表含义、代表性例子、语言与制作指令泄漏。版式遍检查完整语义组、可见对齐、标题入口、容器整组居中、图表内部、所有连线、颜色、字号、页底说明及页码。
3. 每页都实际记录：本页新信息与证据、最大无用空区／最挤区域、标题到有效内容的距离、组内组间节奏及采取的动作。图表数量、色块面积、空盒或统一字号不能证明内容充实。继承现有14项视觉观察的语义范围，不强加不存在的对象。
4. 复杂或测不准区域看当前真实局部并回整页；必要时用另一渲染器或阅读器核对。机器版式失败保留原告警、测量与图像，由另一真实复核者先看图，确认误报或修复后关闭对应项，继续全部验收。复核须覆盖相关对象和邻域，不能作者自授免检。
5. 每次修改重渲染受影响输出，再查原问题和新问题。新建、重做及首次验收必须全量；已有全量签核后用户提出局部修订，才按同等标准复验全部受影响页。主题/宏/字体/页数变化可能影响全稿，范围不清则全量。未变候选的真实渲染可复用。
6. 工作目录保存构建报告、当前PDF与整图/局部哈希、逐页实际观察、问题闭环、独立复核、字号例外及最终签核记录。组件以稳定语义ID、源位置、宏调用实例、frame/overlay和PDF页映射；编辑行号漂移时同步更新。
7. 最终签核确认内容和版式均通过、全部实际页已查、证据对应当前文件、问题已解决；签核后交付PDF与源码包并核对文件一致。受控字体工程按[源码交付方法](bundled-fonts.md#工作工程与源码交付)加入独立准备入口，在工作副本验证重新配置与编译。工具状态 `pending_visual_review` 不能作发布许可。记录只在工作目录，成品保持主题内容。
