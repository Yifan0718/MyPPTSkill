# 默认 Beamer 风格：BIO0507 轻量学术风

用户已将本风格设为长期默认。新Beamer稿未指定其他风格时直接采用，无需重复询问主题；用户指定其他主题、机构规范或自带模板时按该要求执行。封面、页数等需求仍沿用已有确认流程。此默认用于Beamer，PowerPoint继续按其字体和模板独立校准。

## 视觉配置

- 16:9，Boadilla搭配beaver色系。深红标题、浅灰标题区与内容块、白色页面。
- 中文优先FandolHei-Regular，西文Latin Modern Sans。所需字体按[锁定资源](bundled-fonts.md)自动取得并配置，直接按文件加载；保持同一字体及字形，不静默寻找替代家族。
- 正文页主标题以14.5 TeX pt常规体起排；封面题名以19 TeX pt、24 pt行距起排，副标题以12/16 pt起排。封面字号根据题名长度、语言字形、背景框内距及整页视觉重量微调，较长英文题名尤其检查是否横向铺得过满；必要时在完整语义处分行。以上是起点，不能用固定字号或“能放下一行”代替视觉判断。模块标题和色条标题也从常规字重开始，少量有语义的强调保留。
- 默认单行标题条以ht=.57cm、dp=.24cm起排，总高度.81cm；这组值根据FandolHei 14.5pt的实际字形校准。逐页核对标题上下可见留白，混合字体、数学和多行重新精调，执行[标题背景居中检查](precision-layout.md#标题背景中的可见字形居中每页必检)。
- 正文、数学、代码和图表按语义角色保持跨页一致，内容具体充实。复杂公式、机制、代码和多图表继续按真实需要安排。
- 页脚紧凑贴底，文字的真实上下余量均衡；x/y按实际PDF页计数。作者有明确依据才出现，否则使用题名与页码两段，避免空署名色块。
- 所有模块检查实际可见外缘；通栏代码等背景与上下并列组的整体边界呼应，内部文字另保留合理内距。
- 正文页尚无既定布局时，可先试排垂直居中的`[c]`；已有合适构图可沿用，密集页、渐进展示或特定图文结构可选`[t]`。逐页比较标题条下缘至有效内容、有效内容至页脚的余量及内部组间节奏。内容偏上时检查顶端定位和底部余量，偏下时检查标题入口和顶部空区。居中后若标题下方出现大空区，优先重组语义模块、调整图表有效高度与段间距；按[双向重心精调](precision-layout.md#标题尺度与正文重心双向检查)复核，保持内容充实。无需为已合格布局机械生成两套候选。

源码以约3.6mm色带、7.9TeX pt页脚字作为起点，与起步工程10.5TeX pt正文的字号比约为75%。作者/题名组与含斜杠的页码分别校准基线，三个色块逐一检查；不能用中段的余量代替另外两段。实际稿件按[共用字号比例规范](presentation-hierarchy.md#同页字号比例与同层级一致性两种格式共用)核对本页最大普通非标题字号；仅“大数字强调＋较小辅助文字”可排除真实强调数字，再检查其余文字并调整字号与色带余量。ht/dp分别是基线上下占位，不按像素数或正文底边距机械套用。长标题、页脚换行需要调整容器并重新看图。

## 使用

从[起步工程](../assets/beamer-starter/)复制工作副本，在`\input{theme.tex}`后加入：

```latex
\input{bio0507-style.tex}
% 已提供作者时，按真实署名设置：
\renewcommand{\BioFooterAuthor}{作者姓名}
```

题名通过`\title[简短题名]{完整题名}`设置。没有作者时保持BioFooterAuthor为空。源稿内容仍按任务重新组织，不把样式要求或制作说明写进幻灯片。

依次执行[精调](precision-layout.md)、[图表](beamer-charts.md)和[Beamer验收](beamer-workflow.md)。主题是起排基础；逐页内容、实际字形、内外间距、页脚和整体密度照常检查，修订后复验。
