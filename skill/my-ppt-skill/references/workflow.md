# 标准工作流详解

> **强制交付门槛：** 执行 [本地交付标准](local-delivery-quality.md)、[完整布局检查](layout-integrity.md) 和 [签核流程](signoff-workflow.md)。模板风格不能优先于可读性；签核默认全量，严格增量条件见签核流程。

本文档说明三种模式的具体执行步骤，是 `SKILL.md` 的延伸。

## 通用前置：理解用户需求

确定篇幅后遵守 [页数约束与合理拆页](local-delivery-quality.md#页数约束与合理拆页)，不得为通过排版检查机械增页。学术或高级科学图表任务按需要读取 [科学绘图工具与环境选择](scientific-visualization.md)，探测已安装工具后再选择实现。

大纲组织方式不明确且不同结构会明显改变成品时，提供简短备选方案询问用户；相对清楚、已有大纲或已授权自行组织时直接推进，不增加固定的大纲审批。详见 [大纲的条件式确认](local-delivery-quality.md#大纲的条件式确认)。

制作整套演示前，先执行 [制作前需求确认](local-delivery-quality.md#制作前需求确认)：封面需求未说明必须问；页数、约数或范围未说明必须问。用户已经提供的信息不重复询问。默认总页数包含封面，必需答案到齐后才开始正式大纲和页面制作。

不论走哪条路，先抽取下列信息：

| 维度 | 例子 |
|---|---|
| 主题/场景 | 工作总结、开题答辩、述职竞聘、教学课件、商务提案 |
| 主色偏好 | 红色（党政/爱国）、蓝色（商务）、橙色（活泼）、绿色（环保）、黑白（高级） |
| 风格关键词 | 简约、商务、卡通、复古、麦肯锡、扁平、插画、几何 |
| 受众 | 领导、同事、客户、学生、答辩老师 |
| 封面 | 是否需要独立封面；未说明时必须询问 |
| 篇幅 | 精确页数、约数或范围；未说明时必须询问，默认含封面 |
| 数据图表需求 | 有没有真实数据需要可视化 |
| 时间紧迫度 | 是否需要先给预览图让用户确认 |

如果用户没说清楚，先用 1-2 个简短问题搞清楚，再决定模式。

## <a id="mode-a"></a>模式 A：从内置模板挑

### A1. 读 INDEX

```bash
cat templates/INDEX.md
```

INDEX 把所有内置模板按风格分类列出，每个条目带一句 30 字内的特点描述。先按用户输入的"主色 + 风格 + 场景"在 INDEX 里大致缩小候选。

### A2. 读候选模板的 intro.md

```bash
cat templates/<slug>/intro.md
```

intro.md 是高度浓缩简介，包含：
- 一句话定位
- 风格标签 + 排版复杂度
- 主题色（hex）
- 字体
- 适用场景（**故意写得宽泛**，不要被模板原标题局限）
- 包含的页面结构 + 版式类型
- 不要选用的页面

### A3. 决定 / 跟用户确认

- **用户已指定模板** → 直接用。
- **你高度确信唯一最佳**（场景+风格+主色强匹配且明显胜出）→ 可直接用，但先一句话告知选了哪个 + 理由，留否决余地。
- **用户没指定，或你拿不准哪个最合适（默认情形）** → 让用户选：
  - 用当前可用询问工具（不可用则直接提问）通常给 **3 个**候选，每个附一句话理由 + 展示其 `templates/<slug>/preview.png`。剩余有效候选不足 3 个时如实展示，不重复或虚构凑数。
  - 有更多候选时提供「都不满意，换一批」；每批最多 3 个没出现过的候选（带预览图），用尽时进入下一条。
  - 候选用尽仍不满意 → 追问更具体偏好，或转模式 C 原创。
- ⚠️ 不要不看预览图就凭模糊匹配自作主张定模板。

### A4. 读 detail.json，选页

```bash
python3 -c "import json; d=json.load(open('templates/<slug>/detail.json')); print(json.dumps([{'n':p['slide_number'],'role':p['role'],'use_for':p['use_for']} for p in d['pages']], ensure_ascii=False, indent=2))"
```

按用户内容规模选页：
- **封面按用户选择，其他页面按内容需要** —— 读 `page_roles`：
  - 用户要封面 → 优先用 `cover`；`cover` 为空则按正文风格生成独立封面。用户不要封面 → 直接从正文开始。尚未确认 → 先问用户。不能把正文页冒充封面
  - `ending` 非空 → 仅内容需要且篇幅允许时选用结束页；`ending` 为空 → **直接以最后一张内容页收尾**，不要硬造"感谢聆听"
- **目录页**：`agenda` 非空时按需选；多章节才有意义；章节数要和你后面要选的章节扉页数一致
- **章节扉页 + 内容页**：`section_divider` 非空时按章节大纲挑；为空就直接列内容页
- **跳过的页面**：`skip_pages` 数组列出的 + 任何 `auto_promo_flag=true` 的页面

封面作为已确认需求处理，计入总页数；模板无封面时允许按同一视觉系统创建。目录、章节扉页和结尾按内容需要组织，不为凑固定结构硬加。整稿所有页面包括新封面都必须渲染、逐页检查并 signoff。

把选定页面的原模板编号（1-based）按演示顺序放到 `selected_slides` 数组。

### A5. 写 edits.json

完整 schema 见 [`pptx-edit-schema.md`](./pptx-edit-schema.md)。核心要点：

```json
{
  "template_slug": "<slug>",
  "selected_slides": [1, 2, 3, 5, 7, 9, 10, 12, 13, 14, 16],
  "edits": [
    {"slide": 1, "slot_id": "cover_title_cn", "new_text": "..."},
    {"slide": 2, "slot_id": "agenda_ch1_cn", "new_text": "..."},
    ...
  ]
}
```

约束：
- **逐一核查所选页面的 editable=true 槽位**：占位内容必须替换或删除；适用于当前主题的事实、标签和单位可以保留，不要求仅为覆盖 edits 制造空改。
- **`max_chars` 是软性参考、不是硬上限**（中文 1 字=1，英文/数字≈0.5）。尽量靠近容量，但**超过字符估算并非自动失败，但真实渲染不得溢出**；**严禁为凑数而截断文字、在结尾加 `...` / `…` / `等等`** —— 截断与实际超框都不能验收通过。太长就用更精炼的措辞**重写**，或换更大的版式/页面。
- **同一 `level` 的标题保持一致字号**（见 `type_scale`）；优先精简措辞，必要时加宽文本框。模板字号过小时按本地标准统一提高，不逐处缩字或截断加省略号。
- **改了 agenda 的章节文字，必须同步改对应分章扉页 / 面包屑**
- editable=false 的纯装饰 slot 通常保持；实际页码、数据或章节编号须按当前内容同步，不受该提示豁免
- 构建时务必带 `--detail`。`--strict` 校验 expected_text，不控制长度估算。定位或修改失败始终阻断保存。

### A6. 跑构建

```bash
python3 scripts/build_pptx.py \
    templates/<slug>/template.pptx \
    edits.json \
    out/<name>.pptx \
    --detail templates/<slug>/detail.json
```

默认会自动 sibling-lookup detail.json，但显式 `--detail` 更稳。出框检测默认只打印提示、不阻断；`--strict` 用于验证模板原文，不能替代渲染检查。

### A7. 自检

跑 `render_slides.py` 渲染最终 pptx，目测：
- 没有遗留占位文字
- **没有被省略号截断的半句话**：必须消除实际超框，不能用 `...` 代替必要内容；代码续行符或数学记号等有明确语义的省略号按其真实用途保留并检查。
- 文字换行没有明显错乱
- 章节名前后一致
- 顺序符合大纲

发现问题后修改文案或必要的布局，重新生成并渲染受影响页面。最终候选文件全页验收通过后才能交付，检查记录放在工作目录。

## 失败兜底

| 现象 | 处理 |
|---|---|
| `expected_text mismatch` | 模板原文发生变化；重新核对目标与 detail.json 的 current_text，不通过关闭校验掩盖错位 |
| `shape_id not found` | 模板被替换了；要么用其他模板，要么重新提取 detail.json |
| 文字溢出 | 看 `max_chars`；缩短文字或换更宽的版式 |
| 字体不一样 | 见 [`SKILL.md` 字体说明](../SKILL.md)，配置 fontconfig 别名 |
| 图表数据没改 | 见 [`chart-editing.md`](./chart-editing.md) |
