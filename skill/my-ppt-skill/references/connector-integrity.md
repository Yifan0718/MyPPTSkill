# 连接完整性门槛

## 设计与检查

关系图的箭头是语义连接，必须明确来源与目标。优先使用原生连接符绑定真实节点连接点；多段线共用精确端点，移动节点后同步重算路径。不得靠箭头大小覆盖几何断口。尖端贴合实际可见目标边界；路径不得穿字、穿无关节点或与其他线形成含混交叉。转折到目标的最后一段要可辨认，不能收缩成悬空小三角。分支、回路、双向连接分别核对方向。

逐根检查两个端点，不只检查有箭头的一端。顺序是：全图解释源→目标关系；沿线从源追到目标；查看两个端点与每个转折的局部真实渲染；检查实际尖端、边界接触、拼接连续性；回到正常整页。几何合格但可见断口、过冲、错误连接或不明确仍失败。修改后检查全稿同类连接，重新渲染并完成最终双遍验收，不补写旧版本通过记录。

**高风险连接强制加强视觉核验，即使自动检查全部通过。** 短末段、回折/曲线、贴边箭头、多段拼接、分支/汇合、交叉线、组内变换及密集图内部连接，必须单独放大端点、全部转折和交叉处，检查箭头尖端是否真的触达目标、是否收缩成小三角、线段是否连续、是否误连或被遮挡。局部截图须同时包含目标边界和邻近线段；不能只裁出一个三角形。再以正常整页尺寸从源追到目标，确认观众能看懂方向。无法自动测量的区域转入此流程，不能略过或仅填“坐标一致”。

直线箭头末段长度至少为 `max(6pt×页面缩放, 4×线宽)`；不足进入版式待复核。可见退化须调整路径后重渲染；测量失败而当前局部与整页实际合格时可走通用独立视觉闭环。达到长度阈值后，仍须实际检查末段与箭头的可见形态。折线/曲线的实际最后一段及箭头尺寸还必须从局部图检查；不以首尾直线距离替代真实路径。

## 自动门槛与证据

`audit_layout_coverage.py` 自动盘点每页原生直线、折线、曲线、带箭头的形状及组内连线；不按名称、模块声明或用户填写的ID过滤。每根产生 `connector_endpoint_review_required`。图像/SVG/自定义图形里的连接仍必须在现有内部图形检查中逐根局部追踪，不得栅格化以逃避原生检查。

`verify_coverage_review.py` 调用 `connector_integrity.py` 重算清单，要求顶层 `connector_reviews` 精确覆盖，不允许漏项、重复或多项。每根记录：

```json
{
  "slide": 14,
  "shape_id": 42,
  "image_sha256": "当前整页PNG哈希",
  "semantic_relation": "真实来源对象、目标对象与方向含义",
  "path_observation": "实际路径、各转折和交叉、文字/节点避让情况",
  "returned_to_full_page": true,
  "endpoints": [
    {"kind":"shape_boundary", "target_shape_id":12,
     "crop_box_px":[100,100,180,180], "crop_path":"绝对路径.png",
     "visible_tip_and_boundary_observation":"本端点实际笔画与目标边界的接触、方向和周边间隙"},
    {"kind":"shape_boundary", "target_shape_id":13,
     "crop_box_px":[400,100,480,180], "crop_path":"绝对路径.png",
     "visible_tip_and_boundary_observation":"另一端点的独立观察"}
  ]
}
```

端点顺序为 begin/head、end/tail，来自扫描的 `endpoints_pt`。局部 PNG 必须是当前整页的原像素裁剪，四周至少覆盖8pt环境；校验器重读并逐像素比较，不能拿无关局部图或旧图充数。必要时额外放大检查，但不以放大重采样图替换原裁剪证据。

支持的关系：
- `shape_boundary`：实际可见、未旋转的原生矩形/椭圆/菱形节点，检查端点到真实几何边界距离≤0.5pt（按页高缩放）。这是默认数值检查阈值，不是允许可见悬空；数值失败可按通用独立视觉闭环核对实际接触，存在可见断口仍修复。
- `line_junction`：无箭头端可接另一根线的明确 `target_shape_id` + `target_endpoint`（0或1）；相同0.5pt上限。有箭头端不能借无关线接点代替真实目标节点。
- `open_nonrelational`：仅无任何箭头的坐标轴、分隔线、尺寸线、图例线段，`purpose` 为 axis/separator/dimension/legend_sample。仍需两个端点局部图与具体观察。关系连线不能改名套用此项；箭头线不能使用。
- `icon_stroke`：真实紧凑图标笔画，提供完整 `cluster_shape_ids`（如队列三横线、芯片一侧三根引脚）。机器要求至少三根无箭头平行直线、相同跨度、等距分布、48pt内紧凑区域，并检查有没有漏掉紧邻同型笔画。不得用此项处理节点间关系线；复杂不符合此结构的图标需扩展经过回归测试的几何支持，不重命名骗过。
- `arrow_axis`：时间轴/坐标轴本体，`axis_shape_id` 必须为本线，`tick_shape_ids` 至少两个实际相交的垂直短刻度，`label_shape_ids` 至少两个位于不同刻度旁的真实非空文字。验证水平/竖直方向、轴长、刻度长度、相交位置及标签位置，不接受一根自由箭头自称时间轴。
- `axis_tick`：轴刻度笔画，提供相同轴/刻度/标签清单，本线必须在刻度清单里。也要逐端局部图及整页回看，不能因符合轴结构省略视觉核验。
- `data_marker_center`：无箭头的哑铃/数据连接线可接真实实心椭圆数据点中心。提供 `target_shape_id` 和 `data_mapping:{source_path,source_sha256,row_index,column,axis,offset_pt,scale_pt}`；source为CSV，row_index从0计，axis为x或y。机器读取该行该列实际数值，计算 `offset_pt + scale_pt × value`，核对数据点位置；同时检查线端与实际圆点中心一致、点尺寸≤20pt。近值圆点允许按真实数据重叠，不能为了拉开距离改值或移动点；仍须视觉核对遮挡、标签及图例语义。
- `data_reference_line`：无箭头的等值参考线，提供 `data_mapping:{source_path,source_sha256}`。JSON源须含 `equation:"y=x"`、`x_axis:{offset_pt,scale_pt}`、`y_axis:{offset_pt,scale_pt}`、`endpoints_data:[[x0,y0],[x1,y1]]` 和 `source_data_path/source_data_sha256`（底层图表数据）。校验公式、坐标变换、真实端点和源数据哈希；其他公式需新增经过测试的支持，不改名绕过。参考线不是流程箭头，不能用于箭头关系；标签避让、线型及含义仍须实际局部与全页检查。

数据线契约不能用来免检悬空关系箭头：任何端带箭头均拒绝上述两类；数据marker必须是实际小型实心椭圆、端点真实在中心、数字来自指定CSV字段。映射参数应来自真实图表坐标轴，签核须核对其与轴标签和绘图区一致，禁止编造变换来迁就错误线位。文件哈希只保证一致性，不替代数据与视觉判断。

块箭头（rightArrow等preset）也进入独立清单，不再因它不是LINE而漏检。尚未实现可靠端点几何的块箭头保留语义与内容，补充当前局部＋整页独立视觉证据或可验证的原生连接结构；禁止借转换删除关系或降低信息量。

当前机器几何不能可靠解析的组变换、自定义路径或节点不得自动豁免：保全连线清单、目标及当前图像，补充可验证几何或通用独立视觉证据后继续。确有可见问题时再调整结构、重渲染与复核，不要求为取得兜底资格改变正确图形。不得添加透明代理框、把图转成图片或虚构目标规避。工具能力不足是未完成状态，不是通过状态。

清单完整性或局部证据失败须先补全；端点几何等版式规则失败保留原结果并进入待复核，可按签核流程完成局部＋整页独立视觉兜底。未关闭项使最终校验非零且status=failed。旧coverage/旧Skill版本锁会失效，必须重扫。缺陷修复后重新渲染，不能手改报告隐藏失败。证据校验不证明实际看图：最终签核人仍逐根追踪实际视觉与语义；用户/复核指出未解决缺陷时撤销执行者签核。
