# LaTeX 成果交付

所有使用LaTeX制作或修改的成果，包括Beamer、讲稿、文档、TikZ/PGFplots图表，交付时同时提供：

1. 实际编译并完成视觉核验的PDF。
2. 原始可编辑源码及必要的图源、数据、样式、引用与编译说明；多文件工程可打包ZIP，保留字体准备入口及相关许可。

最终回复必须给出PDF的直达打开链接，例如`[打开PDF](完整绝对路径/成果.pdf)`或指向该PDF的实际URL，并另附源码链接。文件卡片、预览截图、文件夹或ZIP链接不能替代PDF直达链接；PDF不能只藏在压缩包中。

交付前核对链接目标存在、PDF可打开、源码对应同一版本。编译或验证失败时修复并继续，保留已有有效材料，完成当前PDF与源码配对后交付。执行记录与制作要求留工作目录，成品呈现主题内容。
